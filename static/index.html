    Use your own window

    POST /api/predict with a JSON object containing window: 256 rows × 8 finite values, in the order below. It returns the actual ensemble prediction and power estimates without adding external data to the simulation ledger.

    voltage, current, power_factor, motor_rpm,
belt_speed, temperature, load, vibration

    Expected sample rate: 1 kHz. Supply RMS electrical values with the configured voltage convention. Arbitrary distributions may still produce confident predictions; this endpoint is not a validated industrial monitor.
